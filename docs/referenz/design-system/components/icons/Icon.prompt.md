Monochrome Lucide icon rendered via CSS mask so it inherits `currentColor`; use for every glyph in buttons, inputs, nav and alerts.

```jsx
<Icon name="log-in" size={18} />
```

- `name`: any Lucide name (kebab-case). Size 16–20px in controls, 24px in icon buttons.
- Intentional addition: source defines no icon set.
