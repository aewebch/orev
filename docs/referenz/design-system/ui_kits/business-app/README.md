# Business App UI kit

Click-through demo of the aeweb element language in a generic business app: Login → Dashboard → Benutzer → Einstellungen, plus the user modal (tabs + footer).

**Layout disclaimer:** the source (`f1/aeweb-design-system.md`) is deliberately layout-independent. The sidebar/grid here is illustrative only — every aeweb app may structure navigation differently. What is binding is the element styling (buttons, inputs, cards, badges, modal, tabs, avatars, dots).

Files: `index.html` (router), `Login.jsx`, `Shell.jsx` (nav + header), `Screens.jsx` (Dashboard, UserList, Settings, UserModal). All primitives come from the compiled bundle.
